# Code review — M4 (Hash estático + HashIndex secundário)

> Formato no `CLAUDE.md`. Achados do code review cruzado usam o prefixo `[RC por Px]`.

### [E07] Limiar de dispersão do teste ignorava o fator de carga
- Arquivo: tests/test_hashfile.py:216  | Categoria: outro (teste)
- Como foi detectado: teste `test_dispersao_no_arquivo` falhou (cv = 0,64 > 0,6)
- Código bruto (tag raw-E07): `assert est["cv_ocupacao"] < 0.6`
- Correção: com o FakeCodec (max_size pessimista) nB fica grande e λ = nr/nB ≈ 2,5; para hash
  uniforme a ocupação é ~Poisson(λ) e o CV esperado é 1/√λ ≈ 0,63. O teste passou a comparar com
  esse valor esperado (`cv < 1,3/√λ`), o que vale para qualquer codec/página.

### [E07] `reorganize()` materializava o arquivo inteiro em memória
- Arquivo: src/access/hashfile.py:395  | Categoria: eficiência
- Como foi detectado: revisão do código bruto (os testes passavam)
- Código bruto (tag raw-E07): `for bno, _ in list(self._blocos_fisicos()):`
- Correção: `_blocos_fisicos` devolve os bytes de todos os registros; o `list(...)` acumulava a
  tabela toda só para obter os nº de bloco. Agora percorre bucket a bucket via `_cadeia`, mantendo
  1 página pinada e só o nº do bloco corrente.
