# Decisões — M1 (Gerente de Arquivos + Buffer Pool)

| # | Decisão | Justificativa | Alternativa preterida |
|---|---|---|---|
| E01-1 | Cabeçalho (bloco 0) **write-back**: lido no `open` (1 leitura), alterado em memória, gravado em `close`/`sync` (1 escrita) | Gravar o cabeçalho a cada `allocate_block` faria o braço ir ao bloco 0 e tornaria aleatória toda escrita de uma carga sequencial, distorcendo seeks medidos | Write-through a cada alteração |
| E01-2 | Lista livre encadeada **no disco**: bloco livre guarda `'LIVR' + próximo`; liberar = 1 escrita, reusar = 1 leitura (contam I/O) | Custo fiel de uma free list encadeada (13.2); a marca permite detectar corrupção | Bitmap de blocos livres no cabeçalho (sem I/O extra, mas limita o nº de blocos ao tamanho do bloco 0) |
| E01-3 | Espelho em memória só dos **números** dos blocos livres (reconstruído no `open` percorrendo a cadeia, com I/O contado) | Valida `read/write/free` de bloco livre (double free) sem cache de conteúdo; a cadeia em disco é conferida a cada reuso | Não validar acesso a bloco livre |
| E01-4 | Extents: arquivo cresce com `truncate` (+`extent` blocos zerados) sem contar I/O; `header()['extents']`, `['proximo']`, `['num_livres']` como chaves extras | Reserva de espaço não transfere blocos; chaves extras ajudam testes/relatório sem mudar o contrato | Escrever o extent zerado (contaria `extent` escritas) |
| E01-5 | Criação do arquivo grava o cabeçalho inicial **sem contar I/O**; `reset_io_stats` zera contadores mas **mantém a posição do braço** | Criação é preparação, não operação medida; o braço é estado físico | Contar a criação / zerar o braço (1º acesso pós-reset sempre seek) |
