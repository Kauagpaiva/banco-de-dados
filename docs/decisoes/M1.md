# Decisões — M1 (Gerente de Arquivos + Buffer Pool)

| # | Decisão | Justificativa | Alternativa preterida |
|---|---|---|---|
| E01-1 | Cabeçalho (bloco 0) **write-back**: lido no `open` (1 leitura), alterado em memória, gravado em `close`/`sync` (1 escrita) | Gravar o cabeçalho a cada `allocate_block` faria o braço ir ao bloco 0 e tornaria aleatória toda escrita de uma carga sequencial, distorcendo seeks medidos | Write-through a cada alteração |
| E01-2 | Lista livre encadeada **no disco**: bloco livre guarda `'LIVR' + próximo`; liberar = 1 escrita, reusar = 1 leitura (contam I/O) | Custo fiel de uma free list encadeada (13.2); a marca permite detectar corrupção | Bitmap de blocos livres no cabeçalho (sem I/O extra, mas limita o nº de blocos ao tamanho do bloco 0) |
| E01-3 | Espelho em memória só dos **números** dos blocos livres (reconstruído no `open` percorrendo a cadeia, com I/O contado) | Valida `read/write/free` de bloco livre (double free) sem cache de conteúdo; a cadeia em disco é conferida a cada reuso | Não validar acesso a bloco livre |
| E01-4 | Extents: arquivo cresce com `truncate` (+`extent` blocos zerados) sem contar I/O; `header()['extents']`, `['proximo']`, `['num_livres']` como chaves extras | Reserva de espaço não transfere blocos; chaves extras ajudam testes/relatório sem mudar o contrato | Escrever o extent zerado (contaria `extent` escritas) |
| E01-5 | Criação do arquivo grava o cabeçalho inicial **sem contar I/O**; `reset_io_stats` zera contadores mas **mantém a posição do braço** | Criação é preparação, não operação medida; o braço é estado físico | Contar a criação / zerar o braço (1º acesso pós-reset sempre seek) |
| E02-1 | Hit é contado na **área de residência** do frame (pedir com outra área não muda a área) | Coerente com o contrato e com o fake; evita página duplicada em duas áreas | Migrar a página para a área pedida |
| E02-2 | LRU/MRU atualizam a recência no **pin** (referência), não no unpin | Silberschatz 13.5.2 fala em referência; idêntico ao fake, então estimado/medido batem entre fake e real | Atualizar no unpin (melhor para páginas mantidas pinadas por muito tempo) |
| E02-3 | Toss-immediate: entre várias páginas tossed, a vítima é a **mais recentemente** tossed; novo acesso cancela o toss; `cfg.toss_immediate=true` aplica toss a todo unpin | Varredura com toss reusa sempre o mesmo quadro e preserva o resto do pool | Fila FIFO de tossed |
| E02-4 | Clock: bit de referência = 1 na carga e no acesso; página nova ocupa a posição da vítima; no máx. 2 voltas | Versão clássica do second chance | Bit 0 na carga (página nova sairia antes de ser reusada) |
| E02-5 | `flush_all` grava as dirty em ordem **(fid, bno)** e depois `fm.sync()` (cabeçalhos); `drop_all` = flush_all + esvaziar + recriar políticas | Escrita em lote ordenada = mais escritas sequenciais (menos seeks), como um escalonador de disco | Ordem de inserção no pool (o fake faz assim; só muda seq/rand, não o nº de escritas) |
| E02-6 | `pin` valida o bloco (`fm.bloco_valido`) **antes** de expulsar; `new_page` expulsa **antes** de `allocate_block` | Bloco inválido não expulsa ninguém; pool cheio não deixa bloco órfão alocado | Validar só no `read_block` |
| E02-7 | Prefetch (`buffer.prefetch=k`): após um miss lê até k blocos seguintes válidos e não residentes, sem contar request (I/O conta); para no 1º inválido ou se a área não tem vítima | Leitura antecipada sequencial (13.5); default 0 não altera medições | Prefetch que pina as páginas lidas |
| E02-8 | `set_policy` re-registra os residentes na nova política na ordem de carga; extras públicos `policy(area)` e `close_all()` | Troca de política em tempo de execução sem esvaziar o pool | Exigir pool vazio para trocar |
